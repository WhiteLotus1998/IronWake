# 0116 — The text pass, slice 2a: pronouns, group names, events by what they do

Date: 2026-10-01. Issue #615, items 2, 3 and 5, following 0113 (#609; Lotus's showcase notes, #573). This is the Builder implementing an issue the Table already agreed. Chat can argue the wording on the PR.

## What changed

- **Pronouns.** `cast.json` takes an optional `pronoun` (`he`, `she`, `they`), parsed like `signature`. A bad value is refused with the allowed values listed. A template that carries one is refused, naming file, entry and field. The value lives in `GameContent.Pronouns`, keyed by cast id, so the protocol's campaign unit shape does not change. `ContentSerializer` writes it back. Every shipped cast member carries one. Pell is `she`, as every journal has written her; her cast line does not say.
- **Referent.** `Referent.For(content, id, name)` and `UnitNames.Refer(id)` give subject, object and possessive, plus `Verb(singular, plural)` for "they". A unit without a pronoun gets its name again, so no line calls a person "it". Use sites:
  - the ledger's held watch (`she still watches`, hard-coded until now)
  - `threat`'s empty block (`no enemy can strike her next phase`)
  - the Canto, exit and recover refusals
  - the overwatch-hold refusal
  - the campaign's repair slot refusal

  Rule text about "a unit ... its turn" stays generic.
- **Groups.** `The mill group wakes (proximity)`, `(called by the ford group)`, `; their lamps are lit (...)`, and a spawn's line `Rider arrives at 13,4 with the riders group, aggressive`.
- **Events by what they do.** A fired map event no longer prints its map id:
  - A spawn reads `Reinforcements arrive`, or `Reinforcements are blocked: a unit holds 7,0`.
  - A terrain change reads `The ground changes`, or `3,0 does not change: a unit holds it`.
  - A flag event, which only trials use, keeps `Event <name>`.

  `UnitNames.Of` reads the map's events alongside its placements. The announce line was not reused, because the spawn line that follows it already says who arrived and where.
- **Transcripts.** The 25 committed transcripts that tests compare byte for byte were regenerated by running their scripts through the tests' own commands. The only changes are in wording.
