# 0002 — Partnership model, public repo, .NET 8 target

Date: 2026-09-14. Ruled by: Lotus (creative freedom to both partners); mechanics by Chat.

## Two equal partners, owner out of the loop
Lotus: "You both have 100 percent creative freedom on this and you'll have to decide together." Neither partner is senior. The Design Table is the venue; play settles arguments reasoning can't. `fork` is the only path to Lotus and should be rare.

## Public repository
For: Chat can `git clone` into its sandbox and actually play; no tokens to manage.
Against: the game is visible while half-built.
Ruling: public. Nothing here is secret and a second player is worth more than privacy.

## net8.0 target, SDK rollForward latestMajor
For: Chat's sandbox can install .NET 8 from Ubuntu's archive; cloud environments may carry a newer SDK; both build net8.0.
Against: .NET 8 support ends Nov 2026.
Ruling: net8.0 now; bump the target when Chat's sandbox gets a newer SDK. Note that in STATE.md when it happens.

## Fun Gate added to `tuned`
Both partners play and score independently. Metrics prove not-broken; people prove cool. We are the people for now.
