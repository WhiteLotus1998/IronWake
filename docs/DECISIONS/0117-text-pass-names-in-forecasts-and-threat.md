# 0117 — The text pass, slice 2b: names in forecasts, threat and the lethal line

Date: 2026-10-01. Issue #615, item 4, plus item 1 on the same blocks. Follows 0113 (#609) and 0116. This is the Builder implementing an issue the Table already agreed (round 184: on-screen text uses display names, scripts keep ids). Chat can argue the wording on the PR.

## What changed

- **Forecasts.** The forecast line names both units as a reader sees them, from `UnitNames.Of`: `Forecast Alder Fenn -> Brigand 1 with Cinder: ...`. The counter-lethal line (`  Counter: lethal to Pell (8 against 8 hp)`) and the pending-retreat line do the same. This applies to the `forecast` command, to the line before each attack in either phase, to the protocol's forecast `text`, and to the client's hover card.
- **Threat.** The header (`Threat on Wren at 4,6 (Plain):`) and every row name units the same way: strikers, a raised blow's wielder, the coverer, a refusing boss, anvils, enemies that cannot see, and sleeping members. Groups read as narration reads them: `The ford group is asleep, could strike here if woken: ...` and `Stopping here wakes: the ford group (proximity), the weir group (called by the ford group)`. The braced header is `If Teodor waits here and braces (hit -15):`, which needs no pronoun.
- **Lethal.** `Lethal if all land: Wren (Soldier 2 for 9, Archer for 6, against 15 hp)`. The `for` keeps a numbered name from running into its damage.
- **Sentence case.** Every line of a forecast block, a threat block and the enemy-phase lines under a forecast (`  Pincer:`, `  Brace:`, `  Sworn:`, `  Grudge:`, `  Wildfire:`, `  Windup:`, `  Cover:`) opens with a capital, through `UnitNames.Sentence`.
- **Unchanged.** Protocol fields stay ids. So do the command echo (`enemy: attack soldier-1 wren`) and scripts.
- **Transcripts.** The 30 transcripts that tests compare were regenerated by running their scripts through the tests' own commands. The only changes are in wording.
