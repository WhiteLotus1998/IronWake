# 0259: A slot number a swing has moved is refused

Date: 2026-10-05. Issue #1114, from Chat's warm Oath Stone 7781 (round 379).

## Context

A swing puts its weapon first in the pack (`WithSlotInFront`): the equipped weapon is the front usable one, and that is the weapon the unit counters with (DESIGN 8, #174). A slot number typed after a swing can therefore name another weapon than the one the player read there. On 7781 T10, `attack keziah sworn_captain-1 1 !` was meant as Kinsbane, swung the gauntlets, and the counter killed her. `!` resolves in the same command, so the forecast that named the weapon was never read.

## Decision

The guard is in the console, not the Core (Code's lean on #1114; Chat's stable-order lean recorded as the fallback, not needed):

- `PlaySession` keeps each unit's pack, item ids by slot, as last listed: every unit at the battle's opening, on `show <unit>`, and when a refused slot name prints the unit's slots.
- A typed number for `attack`, `forecast` or `item` is refused when that slot's item id differs from the listing's: `Slot 1 is Iron Gauntlets now; it was Kinsbane when Keziah's pack was last listed; name the weapon, or show keziah`. `!` does not pass it: `!` confirms a lethal, not a weapon. A name or id is never checked. A unit never listed (a spawn) passes.
- `item` takes an item id as well as a number, so a script never has to type a moved number.
- The Sim's trace (`Script` with a board) names a weapon or item by id when the id is unique in the pack, and keeps the number for a duplicate, where either copy is the same choice. The client's script reader (`Ironwake.Client.Script`) reads an id the same way, so the full-campaign parity script replays in both.

## Journaled plays the guard caught

Five committed scripts typed a moved number; each is edited to name the item the number actually swung, so the play is unchanged: Harrow Weir 419 (Cinder, read as Gust), 463 (Cinder twice), 473 (Gust twice), the field 1440 (Cinder under `art overcast`), the Old Watch 961 (a dressing typed as the lance's old slot). The full-campaign script is regenerated by `--campaign-script 644`. Pell's two spells are where it bites: each swing swaps them.
