# 0348 — Gust becomes Spark Storm in content

Date: 2026-10-08. Issue #1329 slice 3, the first content from #1247 as Lotus signed it (DECISIONS/0347).

## Spark Storm ships (slice 3)

- **The tome `gust` keeps its id** (the issue allowed it). Every journaled script and save names it, so `attack ... gust` still resolves, and is refused with the reason.
- **New numbers:** name Spark Storm; lightning; rank E; Mt 3, Hit 90, Crit 5 (Gust's, which the list doesn't change); range 1-2; area 1; 4 uses; marks. Wt 1 and price 600 are unchanged. The flier tag is dropped.
- **Who has it:** Pell carries it beside Cinder, and the shops stock it where they stocked Gust.
- **It is never an attack.** It is cast with `item <unit> <slot> <unit|x,y>` (0326).

## Fixes the shipped tome made reachable

- **`item ... <x,y> preview` crashed the console** on a tile out of the tome's range. `AreaCast.Forecast` read a distance no strike can have. The preview now asks the same `AreaCast.Unreachable` the cast asks, so it refuses an out-of-range tile, and a tile unseen at dusk, with the cast's words.
- **The attack menu listed an area tome** as plain-attack and art rows. `Queries.AttackOptions` now leaves area tomes out, as it already left out heals.
- **Two refusals named the core's 0-based slot** in a console command (`item Pell 1 <unit|x,y>` for the tome in slot 2). They now name the console's slot.

## Journaled plays stay true to what was played

- 29 replays in the test run attacked with Gust (more countered with it). An attack with an area tome is refused, so on the shipped content those plays no longer replay; they turn into a refusal partway through. Rewriting them would put plays nobody made into the journal. `tools/rejournal.py` would have done exactly that, because it matches only the echoed commands.
- So the tests replay them on **`Fixture.GustContentDirectory()`**: the real content with the one `gust` entry swapped back to Gust as it shipped (`Fixture.GustAsJournaled`).
- Every derived copy (`CopyFiles`) gets the same swap, because each stands for a build journaled before this change.
- The tests that used Pell's second tome to test a mechanic run on that copy too, and say so: weapon names as slots, the greyed menu row, two weapons named on forecast, and the campaign writer's door options and rook_1 side map, whose seeds were read on Gust.
- No transcript is rewritten.
- **Scripts that run on the shipped content are edited by hand:**
  - The full-campaign and Psalter parity scripts are regenerated by the Sim's `--campaign-script`. Seed 644 still wins all 10 maps; the art script still stops after the art.
  - The click-parity carry script swaps its Gust attack for `wait pell`, ends that turn with `end !`, and drops Maud's later commands, because she now falls. The client has no click path for an area cast yet (#1392).
