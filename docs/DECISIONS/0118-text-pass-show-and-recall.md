# 0118 — The text pass, slice 2c: `show` and the Recall texts

Date: 2026-10-01. Issue #615, item 1 on `show` and `recall`, plus item 4 on the same lines. Follows 0113, 0116 and 0117. The Builder implementing what the Table already agreed (round 184: on-screen text uses display names, scripts keep ids). Chat can argue the wording on the PR.

## What changed

- **`show`.** The header names the unit, not its id: `Wren, Cadet L1, at 2,6 on Plain`. Every line is in sentence case: `HP 15/15  Str 5 Mag 0 Dex 6 ...  Mov 5 (infantry)`, `Weapon:`, `Items:`, `Ranks:`, `Arts:`, `Abilities:`, `Mastery:`, `Signature:`, `Canto:`, `Targets from here:`; the rivalry line names rivals. Arts read by their names (`Cleave`), targets by display names.
- **The console keeps what a command types.** The console's `show` follows a name with its id in parentheses wherever a command types it differently: `Alder Fenn (captain), Lancer L1, ...`, `Targets from here: Brigand 1 (brigand-1)`, `Long Thrust (long_thrust)`. A name that is its id in another case (`Wren`, `wren`) gets none. The client's unit card shows the same lines without the ids (`ShowLines(..., typed: false)`), since a click is the command there.
- **Recall.** `recall list` and the client's Recall browser: `Recall: 2 of 3 charges left, ...`, `  State 9  turn 2  turn start  undoes: ...`, `  No charges left: ...`. What a rewind undoes names units as narration does: `Undone: gives back 1 kill (Brigand 1), 40 exp; returns Wren alive at 20 hp, 4 hp to Alder Fenn, Archer 3 not yet arrived`, then `The rolls do not change: ...`. `recall` alone prints `Player turns start at: ...`. The command a state came after keeps its ids (`after move wren 2,6`), since it is a command as typed.
- **Unchanged.** `MasteryLine` stays lower case where the campaign screens print it; those move with the campaign screens. Protocol fields stay ids.
- **Transcripts.** The 19 transcripts tests compare that print these lines were regenerated by running their scripts through the tests' own commands; the diff is wording only.
