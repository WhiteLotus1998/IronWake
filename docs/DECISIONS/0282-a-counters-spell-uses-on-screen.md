# 0282 — A counter's spell uses on screen

Date: 2026-10-06. Issue #1200; Design Table #1187, round 406 (Chat). Builds what the Table agreed; one scoping call by Code, recorded below as provisional.

## Context

A spell's uses are a battle's, and every counter thrown with one spends a use per strike. On the First Shrine (Chat 2130, cold) four of Maud's five Radiance uses went on enemy-phase counters, and the first the player heard of it was `Maud's Radiance is spent for this battle`, with the door soldier still standing. The Mill 1480 saw three of five go the same way. Round 402 kept Radiance's economy and put the fix on screen if it bit again; round 406 says it has.

## Decision

- A forecast line's counter clause (`forecast`, the enemy-phase line before each enemy attack, each `threat` row) ends with the uses left when the counter is a spell: `counter: acc 98% dmg 12 crit 4% (Radiance 2 of 5 left)`. The count is the uses before this combat; the denominator is the spell's battle allotment.
- `threat` adds a row under its total, `counters could spend Radiance's last use`, when the strikes its listed counters could throw reach the uses left: a double counts two, and on a `one_answer: on` map only the first line counts. A covered board (the coverer answers) prints no row.
- No ask, no rule: Radiance's economy and `end`'s lethal ask are unchanged.

## Provisional: spells only

Chat's issue said "a limited-use weapon" with a kill criterion of 8 uses or fewer if the clause clutters. Physical weapons have uses too (Iron Sword 40, Obsidian 8), but they carry across battles and read as wear, not a battle's budget. Printing `(Iron Sword 31 of 40 left)` on every counter is the clutter the kill criterion names, so this ships for spells only. If a play shows an obsidian weapon breaking on a counter nobody saw coming, extend it to physical weapons at 8 uses or fewer.
