# 0113 — The text pass, slice 1: names on screen, the objective in Lotus's words

Date: 2026-10-01. Issue #609 (Lotus's showcase notes, #573 items 4 to 6; Design Table #592, rounds 184 and 185). Builder's implementation of an agreed Table issue. Chat can argue the details on the PR.

## Why

Lotus read the showcase's text as a debug log: unit ids on screen (`toll_warden-1`, `captain`), lines starting lower-case, an objective line full of rule clauses, and key labels that didn't say what the keys do.

## What changed

- **Names, not ids.** `UnitNames` (Core) maps each unit id to its display name. An enemy gets a number only when another unit on the map shares its name. The numbers follow file order, placements first and then spawn events, the same order `MapDefinition.SpawnId` counts in, so a later arrival never renumbers anyone. `PlaySession.Describe` takes the names. The narration, the event log, the protocol's event `text`, the client's log and its act cards all print names. Commands, `--script`, the command echo (`enemy: move archer-2 4,7`), forecasts, `threat` and the roster table keep ids. The roster table is where a console player finds the id for each name.
- **Sentence case** applies to every narration line, each verdict and each Seize notice (`UnitNames.Sentence`). A line that starts with a coordinate is left alone.
- **The objective line** is two short sentences: `Get the captain to the gate by the end of turn 10. Captain Fenn must survive.` That is Lotus's own line for the Tollgate, now pinned by a test. "Captain" plus a surname is the captain's rank and last name. Every win condition has a template. The console prints it as `Objective: ...`, and the client shows the bare line.
- **The rule clauses** are where the tile is, that only the captain seizes, the exit rule, and the boss's mark. They are now `Objective.Rules`, which `help` prints under the commands.
- **The key strip** is `KeyStrip.Keys` in `Ironwake.Client`: `P threat on tile`, `S enemy speed`, `T enemy reach`, `Tab event log`. The footer gap went from 20 to 14 px so the longer labels fit in 1280 (measured from Inter's metrics at 1216 px).
- **Transcripts.** The 30 committed transcripts that tests compare byte for byte were regenerated by running the scripts. Each changed line for line, and only in wording. Scripts replay unchanged, because `--strict` never compared output.
