# 0119 — The text pass, slice 2d: names in the experiment sub-lines

Date: 2026-10-01. Issue #615, item 4 on the lines under a forecast that only sample maps print. Follows 0113, 0116, 0117 and 0118. The Builder implementing what the Table already agreed (round 184: on-screen text uses display names, scripts keep ids). Chat can argue the wording on the PR.

## What changed

- **The sub-lines.** Rivalry, sworn, pincer, brace, break, signature, wildfire and windup lines name units as the forecast line above them does: `Pincer: Brawler pinned by Wren: Ansgar hit +15`, `Brace: Alder Fenn braced: Brigand hit -15`, `Break if Bandit Leader falls: Archer (7/18), Toll Warden (12/26)`, `Signature: Teodor's orders: Wren hit +5`. That holds in both places they print: `ForecastText` (the console's forecast, the protocol forecast's `text`, the client's hover card) and the enemy phase's narration.
- **The enemy phase.** The cover line (`Cover: Teodor takes the strike aimed at Wren`) and the grudge line (`Grudge: Brigand strikes sworn Wren (score 12.0); best alternative Pell (score 9.5)`) name units too.
- **Windup's "its".** "Breaks its blow", "outside its reach" and "at its next phase start" read with the wielder's possessive from `UnitNames.Refer`: the name's possessive for an enemy (`breaks Toll Mauler's blow`), the cast pronoun for a player unit.
- **Ids where no names are given.** Each sub-line builder takes an optional `UnitNames` and keeps ids without one, as `LethalCounterLine` does; the rule tests that call them bare still read ids. The Sim's `--trace` grudge comment keeps ids, because it annotates a script.
- **Unchanged.** Protocol fields, the command echo, and scripts.
- **Transcripts.** The two transcripts tests compare that print a sub-line (Saltmarsh 541 and 547, brace lines) were regenerated by running their scripts through the tests' own commands. The 26 `Contains` assertions on sub-lines were rewritten from a line-for-line diff of the same scripts' output before and after; the diff is wording only.
